# offnets.org

Site público do Offnets em cinco línguas: português (raiz), inglês, espanhol, francês e chinês simplificado.

- `src/<lingua>.html`: o texto de cada língua (linha 1 título, linha 2 descrição, depois o corpo).
- `assets/`: estilo, constelação e o script que lembra o idioma escolhido.
- `./montar.sh` gera `index.html`, `en/`, `es/`, `fr/`, `zh/`, o `CNAME` e o `.nojekyll`.
- Publicado pelo GitHub Pages a partir da branch `main`.

Nada aqui guarda conhecimento de cérebro nenhum: é só a página pública.
