# offnets.org

Site público do Offnets: manifesto, como funciona, origem e a Constituição da rede.

- `src/pagina.html` é a fonte (o mesmo arquivo do rascunho revisado no claude.ai).
- `./montar.sh` gera o `index.html` completo, o `CNAME` (offnets.org) e o `.nojekyll`.
- Publicado pelo GitHub Pages a partir da branch `main`.

Nada aqui guarda conhecimento de cérebro nenhum: é só a página pública.
